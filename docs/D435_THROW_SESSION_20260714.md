# D435i 抛球实测报告（2026-07-14）

## 结论

本次测试证明 RDK 上的 D435 RGB-D、BPU 推理、ROS 2 观测发布和 D435i IMU
发布链路可以稳定运行，但当前方案还不能直接进入真实底盘接球：

- RGB-D 时间、深度有效率和 IMU 传输正常；
- 球检测连续性不足，25 个可见检测片段中只有 5 个形成有效落点输出；
- 第一次稳定落点输出偏晚，5 个有效周期的剩余飞行时间中位数只有 0.287 s；
- 5 个目标按当前底盘速度/加速度限制均不可达，但控制器仍短暂置位了
  `goal_valid`，上线前必须增加在线可达性门控；
- 本次使用静止测试里程计，只验证视觉轨迹链路，不代表真实舵轮里程计或移动接球闭环通过；
- 没有真实撞击时间和落点坐标，因此不能评价绝对落点误差或相机到接球盘标定误差。

## 测试环境

- RDK：`sunrise@10.42.0.225`
- D435i：序列号 `035422071550`，848x480 RGB-D，请求 60 FPS
- 模型：`yolo26n_nashm_640x640_nv12.hbm`
- 视觉进程使用 RSUSB 版 librealsense；系统默认 V4L2/IIO 版不能枚举该内核上的
  Motion Module
- 控制器使用 D435-only 配置
- 里程计：100 Hz 静止诊断里程计 `/test/static_odom`
- 控制输出隔离到 `/test/auto/goal_pose`，未连接底盘
- rosbag：`d435_throw_session_02`，161.598 s，26.7 MiB，57,163 条消息

“即使底盘已处于最大速度仍不可达则拒绝”的上界门控；有真实底盘速度后再使用速度、
加速度和刹车距离的完整模型。

## IMU 结果

静止测试期间：

- 陀螺仪均值：`[-0.00353, 0.00175, -0.00038] rad/s`
- 陀螺仪标准差：`[0.00675, 0.00405, 0.00288] rad/s`
- 加速度均值：`[0.258, -8.993, 3.121] m/s²`
- 加速度模长均值 / 标准差：`9.525 / 0.151 m/s²`

若底盘直接使用当前 y 轴积分航向，静态偏置约为 0.00175 rad/s，理论漂移约
6 deg/min。上线前需要静止零偏估计，并将完整三轴向量从
`camera_imu_optical_frame` 旋转到 `base_link` 后取 base-z 角速度，不能长期只依赖
单一 y 轴和符号。重力分量还提示有效安装俯仰可能接近 19°，与配置的 15° 有差异；
该数值会受 IMU 偏置和 IMU/光学坐标外参影响，应通过静态重力标定确认，不能直接据此改参数。

D435i IMU 只能提供角速度和加速度，不能替代平面 x/y 里程计。本次静止里程计仅用于
视觉算法诊断，真实底盘测试仍必须接入舵轮底盘里程计。

## 上线前必须完成

1. 增加在线可达性门控，不可达目标不得置位 `goal_valid`。
2. 提高球检测连续性；重点补充高速、远距离、小目标、运动模糊训练样本，并检查曝光。
3. 将第一次稳定预测提前到至少 0.8 s；仅降低稳定帧数会增加落点抖动，不能单独使用。
4. 标定 IMU 零偏和 `camera_imu_optical_frame -> base_link` 三轴旋转。
5. 接入真实舵轮 `/odom`，先影子输出，再架空轮测试，最后低速地面测试。
6. 使用撞击传感器、地面网格或外部高速相机记录真实撞击时间和落点，才能验收绝对误差。
