# UCP HBM 模型测试工具

这是一个用于测试 RDK S100 的 HBM 量化模型输入输出信息的工具。可以帮助您了解模型的张量属性、格式、量化信息等，便于修改对应的推理代码。

## 功能特点

- 📦 加载并解析 HBM 模型文件
- 📊 打印模型基本信息（名称、输入输出数量）
- 🔍 获取输入张量详细属性（形状、类型、量化信息、stride等）
- 🔍 获取输出张量详细属性
- 📐 分析 NV12 输入格式详情
- 🎯 分析 YOLO 输出格式结构
- 🧪 测试内存分配
- ⚡ 测试完整推理流程

## 编译

在 RDK S100 板端执行:

```bash
cd test_hbm
mkdir -p build && cd build
cmake ..
make
```

## 使用方法

### 基本用法

```bash
./test_hbm_info <model_path.hbm>
```

### 命令行选项

| 选项 | 说明 |
|------|------|
| `--test-infer` | 执行推理测试 |
| `--test-memory` | 执行内存分配测试 |
| `--all` | 执行所有测试 |
| `--help, -h` | 显示帮助信息 |

### 示例

```bash
# 仅查看模型信息
./test_hbm_info ../model/best.hbm

# 查看模型信息并测试推理
./test_hbm_info ../model/best.hbm --test-infer

# 执行所有测试
./test_hbm_info ../model/best.hbm --all
```

## 输出信息说明

### 1. 模型基本信息
- 模型名称
- 模型数量
- 加载耗时

### 2. 输入张量属性
- **validShape**: 张量的有效形状 (N, H, W, C)
- **tensorType**: 张量类型
  - 0: S8 (有符号8位整数)
  - 1: U8 (无符号8位整数)
  - 2: F32 (32位浮点)
  - 3: NV12 图像格式
  - 4: NV12 分离格式 (Y/UV分开)
  - 8: S32 (有符号32位整数)
- **quantiType**: 量化类型
  - 0: NONE (无量化)
  - 1: SCALE (缩放量化)
- **quantizeAxis**: 量化轴
- **alignedByteSize**: 对齐后字节大小
- **stride**: 各维度步长

### 3. 输出张量属性
同输入张量属性，额外包含:
- **scaleData**: 量化缩放数据（用于反量化）
- **zeroPointData**: 零点偏移数据

### 4. NV12 输入格式分析
- Y平面尺寸和大小
- UV平面尺寸和大小
- 是否为分离模式

### 5. YOLO 输出格式分析
- 输出数量和布局
- 各输出头的形状
- 类别分数/bbox回归识别

## 注意事项

1. 此工具需要在 RDK S100 板端运行
2. 需要安装 UCP SDK (`libdnn.so`, `libhbucp.so`)
3. 推理测试使用全0数据，输出仅供验证流程，不代表实际检测结果

## 相关 API

| API | 说明 |
|-----|------|
| `hbDNNInitializeFromFiles` | 从文件加载模型 |
| `hbDNNGetModelNameList` | 获取模型名称列表 |
| `hbDNNGetModelHandle` | 获取模型句柄 |
| `hbDNNGetInputCount` | 获取输入张量数量 |
| `hbDNNGetOutputCount` | 获取输出张量数量 |
| `hbDNNGetInputTensorProperties` | 获取输入张量属性 |
| `hbDNNGetOutputTensorProperties` | 获取输出张量属性 |
| `hbUCPMallocCached` | 分配缓存内存 |
| `hbDNNInferV2` | 创建推理任务 |
| `hbUCPSubmitTask` | 提交推理任务 |
| `hbUCPWaitTaskDone` | 等待任务完成 |
